# Vanium

Быстрый минималистичный браузер на Electron (Chromium). Тёмная тема с серым акцентом, вкладки сверху или сбоку, интерфейс на русском и английском.

## Возможности

- Вкладки **сверху или сбоку** (переключается в настройках или через меню ⋯), свёртываемая боковая панель, перетаскивание вкладок, закрытие средней кнопкой, контекстное меню вкладки
- Адресная строка с подсказками из закладок и истории (локально, без отправки в сеть)
- Закладки (★), история с поиском и группировкой по дням, менеджер загрузок с прогрессом
- Встроенный **блокировщик рекламы и трекеров** (счётчик заблокированного на странице)
- **Приватное окно** (Ctrl+Shift+N): данные только в памяти, история не пишется
- Стартовая страница с поиском, часами и быстрыми ссылками
- Выбор поисковика: Google, Яндекс, DuckDuckGo, Bing, Brave, Ecosia
- Восстановление вкладок, запоминание размера окна, запрос разрешений (камера, геолокация…)
- Горячие клавиши работают и на русской раскладке

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+T / Ctrl+W / Ctrl+Shift+T | новая / закрыть / вернуть вкладку |
| Ctrl+Tab, Ctrl+1…9 | переключение вкладок |
| Ctrl+L | адресная строка |
| Ctrl+D | закладка |
| Ctrl+N / Ctrl+Shift+N | новое / приватное окно |
| Ctrl+H / Ctrl+J / Ctrl+Shift+B | история / загрузки / закладки |
| Ctrl + = / − / 0 | масштаб |
| Ctrl+R, F5 / Ctrl+Shift+R | обновить / без кэша |
| F11, F12 | полный экран, DevTools |

## Сборка exe через GitHub Actions

1. Создайте репозиторий и загрузите содержимое этой папки (вместе с `.github`).
2. Откройте вкладку **Actions** → **Build Windows** → **Run workflow** (или просто сделайте push в `main`).
3. Готовые `Vanium-Setup-*.exe` (установщик) и `Vanium-Portable-*.exe` появятся в **Artifacts** запуска.
4. Для публикации релиза создайте тег: `git tag v0.1.0 && git push --tags`, exe прикрепятся к релизу автоматически.

Portable-версия хранит данные рядом с exe в папке `VaniumData`.

## Локальный запуск

```bash
npm install
npm start
npm run dist   # собрать exe на Windows
```

## Структура

```
src/main/       главный процесс: окна, вкладки, настройки, adblock, загрузки
src/preload/    безопасные мосты (белый список IPC)
src/renderer/   интерфейс браузера (панель вкладок, адресная строка, подсказки)
src/pages/      внутренние страницы vanium://…
src/shared/     переводы и иконки
```

## Ограничения

- Блокировщик работает по встроенному списку доменов (~140): рекламу внутри видео YouTube и косметические фильтры он не убирает. Для полноценных фильтров EasyList можно подключить `@ghostery/adblocker-electron`.
- Расширения Chrome не поддерживаются.
- Вход в аккаунт Google может быть ограничен самим Google для встроенных браузеров.
- Приложение не подписано: SmartScreen покажет предупреждение при первом запуске.
- Версия Electron в `package.json` (`^44`) обновляется вручную, поддерживайте её свежей ради безопасности.
